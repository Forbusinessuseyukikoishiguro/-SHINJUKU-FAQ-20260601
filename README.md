## このページについて

このページは、IT研修現場ですぐ使える「うさうさ研修工房」の単一HTMLツール **3モード統合版（v4.2.0／商用レベルテスト合格）** を紹介・配布するためのページです。ブラウザで開くだけで動作し、インストールやインターネット接続は不要です。

1つのファイルの中で、上部タブを切り替えると **画面の世界観（背景・配色）ごと** 3つのモードに変わります。

- **講師がつくる**（新宿ビル風）：講師が受講生から聞き取り、記録を整える
- **受講生がつくる**（小学校風）：受講生がレベルに合わせて「前提・仮説・質問」を組み立てる
- **30秒クイズ大会**（おもちゃ風）：受講生が口頭で出題・回答、講師はタイマーと正誤記録

さらに、整えた記録やクイズ結果を **Notion用コピー／メモ(.txt)／PDF／CSV／Excel** で保存できます。

## 📝 作成背景

研修現場では、質問対応や小テストが「その場限り」で流れ、記録が属人化・散逸しがちです。また、対象が新人（非IT・文系を含む）の場合、「良い質問じゃないと聞いてはいけない」と萎縮させてしまう懸念もありました。

そこで、次の3点を1つのツールにまとめました。

- 講師側の聞き取り記録（一次対応・二次対応への接続まで）
- 受講生側が安心して質問を組み立てられる、レベル別の足場かけ
- 理解度チェックを兼ねたクイズ大会の進行と結果の保存

「まず出せたら満点」を土台に、段階的に質問の質を上げていける設計です。

## 前提

- 研修形態（IT基礎／開発／インフラ／セキュリティ）に依存しない汎用構成です。
- 受講生は **役割表記**（受講生A など）で扱い、個人を特定する氏名は記録しない運用とします。
- 記録に含めるのは事実中心とし、所感は分けて扱います。
- 答えに詰まったときは「確認してお返事いたします」で対応します。

## 本題

### ① 講師がつくる（新宿ビル風）

講師が受講生から口頭で聞き取り、ダッシュボード／FAQ用の記録に整えます。

- 単元・質問者（役割表記）・カテゴリ・緊急度を選択
- ①やりたいこと ②状況 ③試したこと ④エラー ⑤受講生の言葉そのまま ⑥聞きたいこと を記録
- 結果に「二次対応へ」を選ぶと、引継ぎテンプレへの接続を促す表示
- 整えた記録を保存（Notion用コピー／メモ／PDF）

### ② 受講生がつくる（小学校風）

受講生本人が、レベルに合わせて質問を組み立てます。

- レベル選択：Lv1「まず出せたら満点」→ Lv2「前提を書く」→ Lv3「仮説をそえる」→ Lv4「前提・仮説・質問で構造化」
- 入力は「前提／仮説／質問／答えの使い道」。空欄でも「一緒に画面を見てもらえますか？」の案内に変換
- できた質問を保存（Notion用コピー／メモ／PDF）

> 「良い質問は前提・目的・仮説があるか」「質問前の3チェック（理解を書き出す・仮説を立てる・答えの使い道を想定）」「前提・仮説・質問で構造化」という考え方を、新卒未経験向けにレベル別でかみ砕いて取り込んでいます。

### ③ 30秒クイズ大会（おもちゃ風）

問題の事前登録は不要。受講生が口頭で出題・回答し、講師は進行に集中します。

- 15秒／30秒の切り替えタイマー（実時刻基準で精度が安定）
- 指名メモ（任意・役割表記）、⭕正解／❌不正解の記録、スコアの自動集計
- 正解で紙吹雪の演出
- 結果を保存（Notion用コピー／メモ／PDF／CSV／Excel）

## 保存（ダウンロード）機能

| 形式 | 用途 |
|---|---|
| Notion用コピー | Notionに貼ると表（クイズ）やコードブロック（質問）として認識される |
| メモ(.txt) | テキストでそのまま保存。ファイル名に日時が自動付与 |
| PDF | 印刷ダイアログから「PDFとして保存」 |
| CSV | 表計算で開ける。文字化け対策（BOM付与）済み |
| Excel(.xls) | Excelが表として開ける形式（追加ソフト不要） |

すべてブラウザだけで完結し、外部サービスへの送信はありません。

## 共通の設計方針（うさうさ研修工房 作法）

- 単一HTMLファイルで完結（外部リソース読み込みなし、オフライン動作）
- 端末標準フォントのみ使用（CORS回避）
- 状態はすべてメモリ内に保持（ブラウザストレージ不使用、リロードで消える）
- `APP_VER` によるバージョン管理（現在 v4.2.0-trimode-dl）
- 起動時に自己テストを自動実行し、画面下部に通過状況を表示
- 役割表記前提で、個人を特定する情報は扱わない

## 品質（商用レベルテスト）

配布前に、静的解析と擬似DOM上での実走テストを実施しています。

- 静的監査：21項目（構文・構造・作法・メモリ・ダウンロード/PDFの堅牢性）通過
- ランタイム検証：21項目（モード切替・連打・出力内容・エッジケース）通過
- 自己テスト：30項目 全通過
- 確認例：CSVのカンマ／改行／引用符エスケープ、Excelの特殊文字エスケープ、文字化け対策、メモリ解放、入力サニタイズ、HTMLエスケープ

### 実機で確認推奨

- PDF出力はポップアップを使うため、ブラウザのポップアップブロックが有効だと止まります（その旨を通知します）。
- クリップボードコピー・バイブレーションは端末（iOS Safari／Android Chrome）での最終確認を推奨します。
